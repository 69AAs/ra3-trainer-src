# 红警3修改器 v1.0.0

给《命令与征服：红色警戒3》用的单机辅助工具。启动游戏后连接，在游戏里按 `Ins` 打开面板，
用**小键盘**就能改钱、改电力、快速建造、消散战争迷雾、复制单位、拉增援 —— 全程不用切出游戏。

## 怎么用

1. 下载 `RA3Trainer-v1.0.0.zip`，解压，双击 **红警3修改器.exe**（单文件，免安装，不用装任何运行库）
2. 在「01 启动」页点「浏览」，选中你的游戏启动器（例如 `ARModLauncher.exe` 或 `RA3.exe`）
3. 点「开启修改」，再点「连接游戏」；没有特殊需求的话，直接点「一键启动并装载」更省事
4. 游戏里按 `Ins` 打开面板，小键盘操作：

```
Num8 / Num2  选行              Num5  执行
Num4 / Num6  调数值（先按 5 进入调节）  Num7 / Num9  换页
Num0 返回                     Ins  关闭面板
```

## 这一版有什么

- **单文件、免安装**：一个 exe，不需要 .NET 运行库，不需要配置
- **游戏内面板**：`Ins` 呼出，选行 / 执行 / 调值 / 换页全在面板上完成
- **认识你的 mod**：自动识别当前 mod（Remix、日冕等），并从 mod 自带数据里读出单位中文名
- **增援单位分类**：按 mod 与阵营分好，不再全挤在「其他」里
- **单位清单会自理**：去重、补全名字；换 mod 或 mod 升级，已记住的单位不会丢
- **数据放用户目录**：设置、单位清单、日志、现场记录都在 `%LocalAppData%\Ra3Trainer`
  （程序放在 `C:\Program Files` 下也能正常用，诊断页有「打开数据目录」按钮）
- **出问题好查**：「04 诊断」页一屏看完连接状态、已启用的功能；可一键导出日志与问题记录

## 运行要求

- Windows 10 / 11（32 位、64 位系统都可以）
- 请与游戏**保持同一个权限级别**：都用普通用户身份启动
  （游戏若用管理员启动，本程序也要用管理员启动，否则连不上）

## 注意

- **只支持单机与人机对战，请勿在联机对战中使用。**
- 改内存有风险，重要进度请先存档。
- 本程序**不联网**、不收集任何数据；部分杀毒软件可能对「读写其它进程内存」误报，添加信任即可。
- 本程序版权归作者所有：欢迎自由下载、自己使用、把**原版压缩包**分享给朋友；请勿修改后二次打包发布或用于售卖。
- 卸载：删除程序文件夹即可；如需彻底清理，再删掉 `%LocalAppData%\Ra3Trainer`。
